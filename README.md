# CodeAlpha Language Translation Tool

A web-based Language Translation Tool built using Python Flask and Deep Translator API that enables users to translate text between multiple languages through a simple and user-friendly interface.

## Features

- Translate text between multiple languages
- User-friendly web interface
- Fast and accurate translations
- Real-time translation output

## Technologies Used

- Python
- Flask
- Deep Translator API
- HTML
- CSS

## Project Structure

CodeAlpha_LanguageTranslator
│
├── app.py
├── requirements.txt
├── README.md
│
└── templates
     └── index.html

## Installation

```bash
pip install flask
pip install deep-translator
```

## Run the Project

```bash
python app.py
```

## Output

- Enter text
- Select source language
- Select target language
- Click Translate
- View translated output instantly
